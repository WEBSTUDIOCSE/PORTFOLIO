tc-invite.tsx — The canvas-rendered TTE character has aria-hidden="true" but the parent <Link> only has aria-label for the link action, not a description of what the visual element IS. A user who can't see the character doesn't know why the invite exists.

🛠️ QA Fixes — Code-Level Solutions

Exact code patches to resolve each defect, based on React 19 and Next.js 16 official docs.

BUG-001 / BUG-004 / BUG-005 / BUG-007 — setState in effect body

Files: JourneyClient.jsx:38, GameIntro.jsx:14, mermaid-diagram.tsx:45, character-scroll.tsx:113

Replace the useEffect mount-gate pattern with useSyncExternalStore — React 19's recommended hydration-safe approach:

// lib/use-is-mounted.ts
import { useSyncExternalStore } from "react";

const emptySubscribe = () => () => {};

export function useIsMounted(): boolean {
  return useSyncExternalStore(
    emptySubscribe,
    () => true,          // client snapshot — always true
    () => false,         // server snapshot — always false
  );
}

// Usage (replaces useEffect + useState pattern):
// Before:
//   const [mounted, setMounted] = useState(false);
//   useEffect(() => setMounted(true), []);
//
// After:
//   const mounted = useIsMounted();

BUG-002 / BUG-006 — Ref mutation during render

Files: JourneyClient.jsx:76, character-scroll.tsx:91

Move the ref sync into an effect:

// Before (render body — BREAKS React 19 strict mode):
storyCompleteRef.current = storyComplete;

// After (effect — runs after render, safe for concurrent mode):
useEffect(() => {
  storyCompleteRef.current = storyComplete;
}, [storyComplete]);

// Same pattern for character-scroll.tsx:
useEffect(() => {
  framesRef.current = frames;
}, [frames]);

BUG-003 — Mutating useThree() return value

File: AutoFitOrtho.jsx:56

R3F's useThree returns an immutable snapshot. Use useFrame's mutable state instead:

// Before (mutates hook return — violates immutability rule):
const camera = useThree(s => s.camera);
camera.zoom = zoom;

// After (useFrame provides the live mutable state):
import { useFrame } from "@react-three/fiber";

useFrame(({ camera }) => {
  if (Math.abs(camera.zoom - zoom) > 0.001) {
    camera.zoom = zoom;
    camera.updateProjectionMatrix();
  }
});

WARN-002 — Dark mode :is() vs :where()

File: globals.css:38

- @custom-variant dark (&:is(.dark *));
+ @custom-variant dark (&:where(.dark, .dark *));

:where() has zero specificity, so dark-mode utilities work at the same priority as their light-mode counterparts.
