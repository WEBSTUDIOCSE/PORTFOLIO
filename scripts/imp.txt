  main      -> Production  (deployed to https://saurabhjadhav.in via Vercel --prod)
  uat       -> Staging     (deployed to Vercel preview URL)
  feature/* -> local development (branched from uat)

One-time setup (run once per machine):
  npm i -g vercel
  vercel login
  vercel link   # from project root - creates .vercel/project.json

-----------------------------------------------

# 1. Start a new feature branch (branches off uat)
.\scripts\new-feature.ps1

# 2. Make changes and commit
git add .
git commit -m "feat: your feature description"

# 3. Merge feature into uat and deploy preview to Vercel
.\scripts\merge-to-uat.ps1

# 4. After UAT testing passes, deploy to Production (saurabhjadhav.in)
.\scripts\deploy-to-production.ps1

-----------------------------------------------

Other scripts:
  .\scripts\push-to-uat.ps1    # Quick push + preview deploy from uat branch
  .\scripts\push-to-main.ps1   # Quick push + prod deploy from main (WEBSTUDIOCSE author)

Notes:
  - Production scripts amend the last commit to author "WEBSTUDIOCSE
    <saurabhjadhav.webstudio@gmail.com>" so the Vercel team picks it up,
    then restore your local git author. Force-push is used because amend
    rewrites the commit hash.
  - Preview/UAT URL is auto-generated by Vercel and printed at the end of
    the deploy.
